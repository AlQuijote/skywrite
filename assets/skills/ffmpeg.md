# FFmpeg assembly and verification

1. Run `skywrite doctor` and `skywrite inspect INPUT`. Burned-in captions (`mode: "burn"`) need `burned_captions.subtitles_filter_available`; if it is false, follow its `fix` hint or keep captions `soft`.
2. Write an edit following `skywrite schema`, with local sources relative to the edit JSON. Source `duration` is output time; `speed` is source seconds per output second.
3. Run `skywrite edit validate edit.json` and review all reported rounding and bounds. Then `skywrite review lint edit.json --transcript WORDS.json` (one per dialogue source): fix `unfinished_ending` and `dead_air` (pauses over 0.6 s; mark deliberate ones in the edit's `pauses` list) and `brief_shot` flash frames (raise `--min-shot-seconds` to match the pacing), and read `not_checked`. Brief shots are checked only between hard cuts; fades and dissolves are not checked yet and black gaps only between full-frame pictures, so watch the short shots `not_checked` points to (`checked.brief_shots_not_checked`).
4. Render directly: `skywrite edit render edit.json --output edit.mp4`.
5. For a portable script, use `skywrite edit export edit.json --to ffmpeg --output render.py`, then `python3 render.py --output edit.mp4`.
6. You can't watch or hear the result: run `skywrite verify edit.mp4 --ends-together --loudness --black --frozen --edit edit.json` (picture and sound end within 0.05 s; -16 ±1 LUFS and -1 dBTP by default, `--target-lufs` for other targets; black first frame and black spans of 0.5 s or more; frozen spans of 2 s or more; `--edit` allows the edit's own fades and stills), quote the numbers, and say what was and wasn't measured (`not_measured`). Then, as far as you can, inspect the rendered MP4 across cuts, layers, fades, delays, empty timeline, held images, retiming, gain keyframes and audio tracks. Rotated phone footage (`rotation` in `skywrite inspect`) renders, describes and sheets upright by its displayed size, and `skywrite verify FILE --expected-width W --expected-height H` checks that displayed size. Confirm duration and streams against the approved edit.

Renders, exported scripts and `skywrite audio` loops give the same picture and sound on FFmpeg 5.1 or newer, including 7.0 and 7.1 (black lead-ins before late-starting video, crossfaded loops of short cues, the start of stretched clip audio, MP4 durations); docs/validation.md has the measured versions. With rubberband, a stretched pure tone after digital silence inside a clip can come out up to 15 dB low; check sustained tones. Use explicit `--overwrite` only for an intended output replacement. The generated script needs Python's standard library and installed FFmpeg. Unsupported effects must be authored in a composition or NLE instead of being silently omitted.
