# Changelog

All notable changes to Skywrite are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 1.0.0 - Unreleased

### Added

- First public release of Skywrite, licensed under MIT, copyright 2026 FlyCockpit LLC.
- JSON-first media inspection, frame sampling and optional OpenRouter analysis and transcription with word timestamps.
- Multi-recording synchronization by audio waveform or transcript, with drift estimates and quality reporting; `strong` needs method-level residuals (`strong_p95_limit_seconds`: 5 ms for waveform, 50 ms for transcripts), and mappings are reported without float noise (an exact match is `scale` 1.0).
- `skywrite sync apply` places a sync result into an edit (frame-grid start, sub-frame `source_in`, drift `speed`, duration trimmed to the real overlap, reference sound muted), refuses results that are not `strong` with drift estimated unless `--allow-limited`, reports `uncovered` timeline, and with `--verify` renders and re-syncs each placed clip. Audio sync measures pre-emphasized waveform anchors every 2 s across the overlap (at most 1800) with sub-sample peak interpolation, and reports takes that one mapping cannot fit (a cut, dropout or recorder restart) as `discontinuous` with located `segments` (each stopping 0.3 s short of a boundary); sound inside a matched stretch that fits no mapping makes the result `limited`; anchors carry their `segment`; `candidate_matches` counts waveform probe windows.
- Edit JSON format version 1, with validation, lint and review tools and a native FFmpeg MP4 renderer. Clip audio is sample-exact at speed 1 and at clock-drift speeds within 0.1% of 1 (resampled); larger speed changes keep pitch with `--stretcher auto|rubberband|atempo` (default `auto`: FFmpeg `rubberband`, latency-compensated by a per-speed calibration to within about 6 ms (8 ms at 0.125x), falling back to `atempo` with a warning when FFmpeg lacks it). The same applies to `audio tempo` and exported FFmpeg scripts.
- Required transcript content fingerprints for transcript-based caption tracks, `describe frames --transcript` and `review lint --transcript`, matching analysis and edit suggestions; byte-identical media copies are accepted, and media SHA-256 hashes are cached locally.
- Export to FCPXML, Premiere XML (xmeml), Hyperframes, Remotion and FFmpeg scripts; import Premiere/FCP 7 XML and experimental `.prproj` files.
- Remotion exports pin `remotion` and `@remotion/cli` 4.0.546, whose own zod pin (4.6.7) carries the GHSA-mrhx-c7xc-m3w5 fix, so the project needs no `overrides` and Remotion prints no version-mismatch warning.
- Exact-timing evidence (`inspect --exact-audio`, `verify`) names its decoder compactly as `decoder: {ffmpeg_version, build_sha256}`, the hash covering the whole `ffmpeg -version` output, instead of embedding that banner; timing evidence is `version` 2 under `audio-timing-v2`.
- Premiere XML fits every video clip to the sequence with a Basic Motion Scale, as the renderer does for square-pixel sources, using the displayed size of rotated phone footage; `inspect` reports a video stream's display `rotation`, and `review lint` uses the displayed size to judge full-frame B-roll.
- `edit export --media-root FOLDER` writes FCPXML and Premiere XML media URLs beneath the editor's folder, so exports made on another machine (for example in the cloud) link on open.
- Native HTML or JSON still graphics through embedded Takumi, with PNG, JPEG and WebP output.
- Optional image, video, narration and music generation and upscaling through OpenRouter, with durable generation projects and optional S3/R2 uploads.
- Generation exit contract: `generate`, `upscale video` and `jobs resume` exit 0 only for a completed or still-running job; other end states exit 1 with `{"error":{"code","message","job"}}` (`not_sent`, `job_not_submitted`, `job_uncertain`, `job_received`, `job_rejected`, `job_failed`). A submission whose connection failed before any byte was sent returns the job to `prepared` ("nothing was billed, rerun the same command") instead of leaving it uncertain; split narration sections and project nodes follow it. Nothing is retried automatically.
- `skywrite audio roomtone SPEECH --bed ROOM -o OUT`: dry speech loudness-normalized first (`--lufs`, default -18), a room-tone bed resampled, optionally high-passed (`--bed-highpass`), set to a measured target level (`--bed-dbfs`, default -58 dBFS RMS), looped with equal-power crossfades or trimmed, summed with `amix normalize=0` and no later loudness pass; output length equals the speech. Unusable beds (missing, silent, too loud, too quiet, under 1 s) are refused; the JSON report has the measured speech, bed and mix levels.
- `skywrite audio inputs` lists capture devices through the system FFmpeg (PulseAudio/PipeWire, ALSA, macOS avfoundation, Windows dshow) without recording. `skywrite audio record-bed --seconds N -o bed.wav --confirm` records room tone only with explicit consent: mono 48-kHz PCM16, a measured 4-s start-up lead discarded, never uploaded, with level, hum share, crest factor, transient and speech-likeness measurements and warnings, and macOS permission problems explained.
- Agent skills, saved style prompts, task model defaults and `skywrite nit` feedback capture.
- Named model providers: `skywrite providers add NAME --base-url URL [--key-env VAR] [--header NAME=VALUE] [--timeout SECONDS]`, `list`, `show` and `remove` register OpenAI-compatible servers (local llama.cpp, Ollama, LM Studio, other hosts) beside the built-in `openrouter`, storing only the name of a key's environment variable. Model references are `PROVIDER:MODEL` (`local:qwen3:0.8b`) wherever a model is accepted; bare and `vendor/model:variant` IDs stay OpenRouter's. Analysis, frame and video descriptions, standard multipart transcription and edit suggestions can use any provider; generation stays on OpenRouter. Other providers never receive OpenRouter-only fields or keys, plain `http://` warns outside loopback and private networks, response caches key on the provider, an unreachable server fails once without retrying, `models list --provider NAME` lists a server's `/models` with unverified capabilities labeled, and `doctor` checks provider reachability.
- On-device transcription with NVIDIA Parakeet TDT 0.6B v3 through the built-in `ondevice` provider (`--model ondevice:parakeet-tdt-0.6b-v3`): runs in-process on transcribe.cpp/ggml (Metal on Apple silicon, CPU elsewhere), free, no key, audio stays on the computer. Its pinned 740 MB model is downloaded only by `skywrite models download` or `transcribe --download` (resumable, size-bounded, SHA-256-checked, re-verified before each use), listed with status and its CC BY 4.0 attribution by `models list --provider ondevice` and `models list --task transcription` (`ondevice_models`), and deleted by `models remove`. Transcripts keep every guarantee (real token word times, source-time shifting, low-audio flags, ordering, `usage.source_sha256`); chunk usage records engine, backend, threads and model hash at `cost: 0`. Scribe v2 stays the default; see the dated evaluation in docs/model-evaluation.md. Building from source now needs cmake and a C++ compiler unless `--no-default-features`; Linux release binaries stay static (built in Alpine) and x86_64 needs AVX2 for the on-device engine only.
- `skywrite doctor` reports whether this FFmpeg has the `rubberband` filter (`audio_stretcher`) and the libass `subtitles` filter that burned-in captions need (`burned_captions`). When `subtitles` is missing it adds a `fix` hint: `ffmpeg-full` on macOS, or a distribution FFmpeg built with libass on Linux.
- Release binaries for Linux (static musl: x86_64, aarch64; no glibc requirement) and macOS (Apple silicon, Intel) on GitHub Releases, with SHA256SUMS, third-party license notices and signed GitHub build provenance attestations for every asset (`gh attestation verify <file> --repo FlyCockpit/skywrite`); archives include the embedded Geist font license as `fonts-OFL.txt`, and Linux archives include the statically linked musl libc's notice as `musl-COPYRIGHT.txt`.
- `external_sources` in every render and export result lists sources outside the edit file's directory; symlinked and special-file sources are refused, in edits and in imported XML. Edit and XML files are documented as trusted input.
